# DayPay

جزئی از سوپراپ D. شناسهٔ دامنه: `Dpey`. پوسته ندارد.

قرارداد زبان: لینوکس x86-64 GAS ۲.۴۰ / GCC 12.2، اندروید ARM64+Smali و API 24 بدون جاوا و WebView، iOS با Swift 5.9 و حداقل iOS 16.

مرورگر و وب‌اپ همان ورودی لینوکس را اجرا می‌کنند. منطق محصول جاوااسکریپت نیست.

نقش و خدمت دریافتی فقط در ماژول احراز هویت ذخیره می‌شود. این مخزن پایگاه‌داده ندارد.
